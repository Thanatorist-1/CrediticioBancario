Ingresar una solicitud de crédito

La solicitud se guardará en la base de datos y será visible inmediatamente para un trabajador.

Ingresa un nombre de 2 a 120 caracteres.
Ingresa un DNI de 8 dígitos.

Flujo del Sistema

Al enviar la solicitud se procesa directamente en el servidor y se almacena en PostgreSQL.

  1. Llenas los datos del formulario.
  2. El controlador recibe la petición POST.
  3. El servicio coordina el guardado con el repositorio JPA.
  4. Se actualiza la vista con el resultado.
