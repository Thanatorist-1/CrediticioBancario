# Sistema bancario integrado — datos simulados

Esta versión consulta la API 8081 para altas de clientes, solicitudes y decisiones automáticas. Incluye una carga académica idempotente de 50 clientes y 1–3 solicitudes por cliente y muestra los indicadores externos en el detalle del trabajador.

Para **arranque, limpieza y pruebas**, leer `../LEEME_INTEGRACION.md`.
